# 各平台播放方式

状态：已实现。

## 设置入口

在「设置 → 播放与换源 → 各平台播放方式」列出歌曲平台。点选平台后，选择模式和受支持的播放方式。已选方式缺少卡密或启用的脚本时，显示配置入口。

| 模式 | 如何播放 |
| --- | --- |
| 自动 | 沿用当前的播放和换源规则。首次配置前默认使用此模式。 |
| 优先 | 先尝试选中的方式。取不到整曲或起播失败时，先试同平台的其他方式，再按全局规则决定是否换平台。 |
| 固定 | 只用选中的方式自动播放整曲。起播失败或只能试听时，停在当前歌曲，说明原因并提供「仅本次换源」。 |

| 歌曲平台 | 可选的播放方式 | 用户示例 |
| --- | --- | --- |
| 网易云音乐 | 平台直连、洛雪 | 优先洛雪，同首歌可用的脚本依现有洛雪顺序尝试。 |
| Apple Music | 平台直连、聆澜卡密 | 优先聆澜卡密，从 Apple Music 的搜索结果或歌单直接播放。 |

搜索、歌曲链接、歌单和收藏保持歌曲平台的归属。平台列表只显示一个 Apple Music，聆澜卡密配置放在 Apple Music 的播放方式设置内。旧「Apple Music（卡密）」条目按相同歌曲 ID 识别为 Apple Music 歌曲，沿用已保存的卡密。

切换播放方式时保留平台登录。平台账号可继续用于应用已支持的账号功能，例如网易云个人歌单。选择聆澜取流时只使用该服务的卡密。

## 与现有换源的关系

- 从平台搜索或平台歌单点歌时，先遵循该平台的优先或固定设置。模式为自动时沿用现有行为。
- 从聚合结果点歌时，先由全局设置选择平台，再应用该平台的播放方式设置。自动换平台时按全局设置选下一候选，进入新平台后应用新平台的设置。
- 「仅本次换源」按当次手动选择播放，之后的自动播放继续使用已保存的设置。已下载歌曲可以直接在本机播放。
- 起播以播放器接收并开始播放音频为准。目录里的试听地址也按试听处理。优先模式用尽整曲候选后，再按现有「允许试听」规则处理。

播放页显示实际使用的方式。优先方式失败并回退时说明去向，固定方式失败时说明原因。队列切歌和播放出错后的重试遵循同样的取流规则。

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 已登录网易云且配置优先洛雪 | 有可用洛雪脚本时先播该脚本，个人歌单仍可访问。 |
| Apple Music 设为优先聆澜卡密且卡密失效 | 说明卡密不可用，尝试 Apple Music 直连，后续按全局换源规则处理。 |
| Apple Music 设为固定聆澜卡密且只有试听或无法起播 | 说明原因，保留手动换源操作。 |
| 固定方式失败后手动换源并播放下一首 | 仅失败的那首采用手动选择，下一首继续按各平台设置播放。 |
| 全局固定网易云，且从配置为优先聆澜的 Apple Music 歌单点歌 | 先尝试聆澜卡密，再按优先模式的规则回退。 |
| 全局固定网易云，且从聚合结果点歌 | 全局先选网易云，在网易云内应用其播放方式设置。 |
| 聚合播放允许从 Apple Music 自动换到网易云 | 换到网易云后使用网易云的方式设置，播放页显示实际路线。 |
| 队列自动切到一首带试听地址的 Apple Music 歌曲 | 优先或固定模式都会先尝试已选方式。固定模式只接受整曲。 |
| 升级时已有旧「Apple Music（卡密）」歌曲及卡密 | 旧歌曲仍能识别为 Apple Music 目录曲目，已保存的卡密可继续使用。 |

另见 [播放与换源术语表](GLOSSARY.md)与 [ADR-0003](../adr/0003-per-platform-playback-routing.md)。
