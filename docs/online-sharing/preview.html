规则

  • 只有「可收听」才有链接；「等待音频」「失败」才能重传。
  • 「已撤销」「已过期」不再提供撤销，也不允许新的播放。
  • 整曲与片段是两种模式，一个链接只对应一种。

这份原型在演示什么

  1. 1选句层：点句子增减（最多 8 句），顶栏计数与「分享」。
  2. 2分享页：卡片预览（色块 / 叠卡 / 播放页三款是真外观）+ 样式、配色、圆角、封面形状；下方「在线听歌」按状态渲染。
  3. 3片段编辑页：时间轴双端手柄、播放头、试听；没有时间戳时整块禁用并说明原因。
  4. 4设置 · 在线分享：服务地址、令牌、我的分享列表（复制 / 撤销 / 状态词）。
  5. 5状态总览：7 个状态词集中核对用词。

占位说明：色块 / 叠卡 / 播放页三款是真实外观，其余 7 款用虚线标签占位；封面用渐变代替真实图片。
