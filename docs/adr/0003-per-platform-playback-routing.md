# ADR-0003：各平台独立选择播放方式

2026-11-27 · 已确认并实现

## 决定

歌曲平台标识用于搜索、歌单和收藏。一个平台可配置多种播放方式，例如 Apple Music 可选择平台直连或聆澜卡密。平台账号沿用自己的登录状态。

从平台入口点歌时先采用该平台已配置的优先或固定方式。从聚合入口点歌时，全局规则先选平台，再用该平台的方式设置。优先方式失败时先尝试同平台整曲，固定方式失败时保留当前歌曲并允许仅本次手动换源。

## 原因与影响

独立注册一个卡密平台会重复展示 Apple Music 目录，也会让搜索结果和歌单条目依赖取流方式。把播放方式归到现有平台，可让同一首歌用不同方式取流。升级需识别旧平台标识与已存卡密，重试需区分同平台内失败的播放方式。

完整交互和验收场景见 [各平台播放方式](../playback-routing/DESIGN.md)。
