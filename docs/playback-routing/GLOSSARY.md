# 播放与换源术语表

**歌曲平台**

提供歌曲目录的平台，例如网易云音乐、Apple Music。搜索结果和歌单条目都有所属的歌曲平台。

**平台账号**

用户在歌曲平台上的登录身份，可用于查看个人歌单、同步收藏等应用已支持的账号功能。

**播放方式**

为一首歌取得实际播放音频的方式，例如平台直连、洛雪或聆澜卡密。同一个歌曲平台可以提供多种播放方式。

**优先播放方式**

为一个歌曲平台指定的首选方式。首选方式无法播放整曲时允许自动回退。

**固定播放方式**

为一个歌曲平台指定的唯一自动播放方式。该方式无法播放整曲时，由用户决定是否仅本次手动换源。

**换平台**

在另一个歌曲平台找到匹配的歌曲，并使用该平台的播放方式。
